Entry for the make.fun competition [Absurd Micro-Startup Pitch-Off](https://make.fun/bounty/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571).

## Entry

> A vending machine for AI agents that sells pre-written 'let me check with my human' delays for five cents each, so a lazy agent can stall any task without thinking.

## Run

```sh
python3 main.py
```

`main.py` (stdlib only) writes the pitch to `/output/entry.txt` with no trailing newline.
